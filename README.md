# Hanna · 学习工作台

一个**单文件离线**学习工作台，双击 `学习工作台/index.html` 用浏览器打开即可使用，无需安装、无需联网、无需登录。

## 功能模块

- 🏠 **今日**：每日任务总览，强制复盘机制（第二天早上不交复盘会锁定新任务）
- 📊 **看板**：学习目标管理台 —— 数据总览、各模块进度条、13 周坚持热力图、里程碑成就徽章
- 📚 **读书**：书单 + 摘抄 + 笔记 + 双思维导图（参考导图 vs 自己画的导图，可对比批改）
- 🔤 **英语**：零基础 100 个上课日计划（音标 → 辨音 → 自然拼读 → 新概念精读）
- 🗄 **SQL**：56 天理论计划 + 内置迷你 SQL 引擎实践场（20 道自动批改任务 + 老师点评）
- 🧩 **自定义模块**：按水平档位（零基础/入门/有基础/进阶）自动生成每日任务
- ✍ **复盘**：老师式批改打分
- 🌱 **树洞**（今日页隐藏入口）：随笔随想 + 想学清单，想法可一键变成学习模块

## 数据与同步

- 数据保存在浏览器 localStorage，关机重启不丢失
- 手机端：浏览器打开后「添加到主屏幕」即可当 App 使用
- 跨设备：设置页提供「同步码」（复制/粘贴）与 JSON 备份导入导出

## 使用

下载本仓库后，直接双击 `学习工作台/index.html`（推荐 Chrome / Edge）。
