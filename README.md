## 🧊 冰箱管家 · 低碳生酮版（首页）

低碳生酮饮食的冰箱库存管理应用。

- 📦 **冰箱库存**：份/颗/斤分装管理，三温区（🏠常温 / 🧊冷藏 / ❄️冷冻），保质期自动估算与临期提醒
- 🍽 **饮食记录**：每餐自动扣减库存，可「撤回」返还
- 🥑 **菜谱推荐**：28 道生酮菜谱，按库存自动排序「现在就能做」
- 🍃 **应季食材**：按月推荐应季食物
- 🛒 **购物清单**：采购完成自动归类入库（自动分温区、标保质期）
- 🗺 **低碳生酮食物地图**：8 大类红黄绿灯食物分级
- 📱 移动端适配，可添加到手机主屏
- ☁️ **同步码**：导出/导入，手动跨设备迁移数据

## 💧 喝水助手 · 待办提醒（water-todo/）

定点喝水提醒 + 待办到期提醒。

- 💧 喝水提醒：自定义间隔与时段
- ✅ 待办事项五种类型：单日 / 每天 / 每周 / 工作日（自动识别法定节假日与调休）/ 自定义日期
- 📔 日记：可设置密码保护（AES 加密，存储于本机浏览器）
- 📱 PWA，可安装到手机主屏

> 注意：在线版为纯前端，数据不跨设备同步；桌面端完整版（三端同步）运行于本地服务。

## 📚 学习工作台（学习工作台/）

一个**单文件离线**学习工作台，双击 `学习工作台/index.html` 用浏览器打开即可使用，无需安装、无需联网、无需登录。

### 功能模块

- 🏠 **今日**：每日任务总览，强制复盘机制（第二天早上不交复盘会锁定新任务）
- 📊 **看板**：学习目标管理台 —— 数据总览、各模块进度条、13 周坚持热力图、里程碑成就徽章
- 📚 **读书**：书单 + 摘抄 + 笔记 + 双思维导图（参考导图 vs 自己画的导图，可对比批改）
- 🔤 **英语**：零基础 100 个上课日计划（音标 → 辨音 → 自然拼读 → 新概念精读）
- 🗄 **SQL**：56 天理论计划 + 内置迷你 SQL 引擎实践场（20 道自动批改任务 + 老师点评）
- 🧩 **自定义模块**：按水平档位（零基础/入门/有基础/进阶）自动生成每日任务
- ✍ **复盘**：老师式批改打分
- 🌱 **树洞**（今日页隐藏入口）：随笔随想 + 想学清单，想法可一键变成学习模块
